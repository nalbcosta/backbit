# Voice

## Purpose
Backbit copy should sound like a real product with a clear opinion.
It should be confident, human, and direct.

## Voice principles
- Product-first.
- Short and useful.
- No filler.
- No corporate buzzwords.
- No generic AI tone.
- No fake excitement.

## Writing style
Use simple language that gets to the point quickly.
Prefer statements that explain value over slogans that sound clever.

Good qualities:
- Clear.
- Calm.
- Precise.
- Slightly editorial.
- Human.

Avoid:
- "Revolutionize your experience".
- "Unlock the power of".
- "Seamless end-to-end".
- "AI-driven next-gen".
- Empty hype.

## Product voice
Backbit should sound like a tool made by someone who actually uses it.
The tone should feel sharp enough for enthusiasts, but still easy to understand immediately.

## Microcopy rule
Microcopy should help the user move.
If a line does not guide action, clarify value, or reduce friction, remove it.
