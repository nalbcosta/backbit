# Typography

## Purpose
This type system is built for a cinematic product with a strong editorial personality and a practical mobile UI.

## Font roles

### Serif display
Use the serif only for emotion, identity, and high-impact moments.

Use cases:
- Hero headline.
- Section titles.
- Large game titles.
- Pull quotes.
- Key stats or featured numbers.

Recommended behavior:
- High contrast.
- Elegant, but not fragile.
- Best at larger sizes.
- Never overused in dense interface areas.

### Sans-serif UI
Use the sans-serif for everything that needs clarity and speed.

Use cases:
- Navigation.
- Buttons.
- Forms.
- Metadata.
- Labels.
- Helper text.
- Cards and list content.

Recommended behavior:
- Minimal and neutral.
- Strong mobile readability.
- Works across small and dense layouts.
- Holds the interface together without stealing attention.

## Pairing rule
The serif creates mood.
The sans-serif creates structure.

If both fonts try to be expressive at the same time, the product loses focus.

## Suggested scale
Use a compact, product-friendly scale:
- display.
- h1.
- h2.
- h3.
- body.
- small.
- caption.

## Style rules
- Limit the project to two families.
- Keep weight usage restrained.
- Prefer semibold for emphasis.
- Avoid overly decorative letterforms.
- Prefer strong hierarchy over font variety.
- Do not use the serif for long paragraphs.

## Tone
The final result should feel cinematic, readable, and controlled.
It should look like a product with personality, not a typography experiment.
