# Layout

## Purpose
Backbit should feel fluid, focused, and mobile-native.
The layout must support quick scanning, quick decisions, and low-friction navigation.

## Structure
- Mobile-first by default.
- Single-column content first.
- Clear sectional rhythm.
- Card-based content where useful.
- Bottom navigation for core app areas.

## Spatial system
Use a consistent spacing scale and avoid ad hoc gaps.
Favor rhythm over randomness.

Recommended spacing logic:
- Tight spacing for metadata.
- Medium spacing for related content.
- Larger spacing between sections.
- Strong top and bottom breathing room for feature blocks.

## Hierarchy
Each screen should answer these questions quickly:
- What is this?
- What can I do here?
- What is most important right now?

Use size, weight, and spacing before color to create hierarchy.

## Mobile behavior
- Keep major actions reachable with one hand.
- Avoid dense multi-column patterns on small screens.
- Prioritize scrolling over pagination where possible.
- Keep primary actions visible.
- Make transitions feel intentional and smooth.

## Visual tone
The layout should feel editorial and deliberate.
It should not resemble a default admin panel or a generic SaaS dashboard.
